# MA-653: Computational Finance Modelling — Lab Assignments

Solutions to the five lab assignments of **MA-653 (Computational Finance Modelling)** at IIT Mandi, built around the Spanish **IBEX 35** index and its constituents.

| Assignment | Highlights |
|---|---|
| [Assignment-1](Assignment-1) | Builds a 15-year IBEX 35 constituent history, adjusts for splits and dividends, and assembles a master price database |
| [Assignment-2](Assignment-2) | June 2010 – Dec 2025: daily returns and summary statistics, tail events, histograms and QQ normality checks, and correlated pairs |
| [Assignment-3](Assignment-3) | Python solutions (Q1–Q5) with a report |
| [Assignment-4](Assignment-4) | Python solutions with a report |
| [Assignment-5](Assignment-5) | Python solutions with a report |

Each folder contains the question paper, the code (`Q*.py`), the generated results and `Report.pdf`. `All-Zips/` holds the archives as submitted.

pip install pandas numpy scipy matplotlib yfinance openpyxl
